## Emojidex Seeding System (Simulated)

Labyrinth2D features a unique (currently simulated) system called "Emojidex Seeding" that allows you to use strings of standard emojis to influence the generation of your rooms. This adds a fun, thematic, and surprisingly deep way to get varied results.

### How It Works (Concept)
The idea is that each emoji carries some "semantic weight" or "memetic token" that translates into specific aspects of procedural generation. For instance, a "fire" emoji might suggest a fiery theme, while a "gem" emoji might increase treasure density.

Currently, Labyrinth2D simulates this with a small, hardcoded list of recognized emojis and their effects:
*   `🔥`: Adds to seed, suggests `{"theme": "fire", "wall_char": "F"}`.
*   `💎`: Adds to seed, suggests `{"treasure_density": 0.8}`.
*   `✨`: Adds to seed, suggests `{"magic_level": 0.3}`.
*   `🌲`: Adds to seed, suggests `{"theme": "forest", "floor_char": "f"}`.
*   `🌊`: Adds to seed, suggests `{"theme": "water", "floor_char": "w"}`.
*   `💀`: Adds to seed, suggests `{"difficulty_mod": 1.2, "theme": "crypt"}`.
*   `🤖`: Adds to seed, suggests `{"tech_level": 0.8, "wall_char": "M"}`.

Unrecognized emojis also contribute to the numerical part of the seed, so any string will produce a unique outcome! The system combines these effects to produce a final numerical seed and a dictionary of `room_params` that are then fed into your `generate_room(seed, room_params)` script.

### How to Use Emojidex Seeding

1.  **In the Level Creator:**
    *   When editing a room's properties, you'll find an "Emoji Seed String" input field.
    *   Enter your desired emoji string here (e.g., "🔥💀✨").
    *   This string will be saved with the room's definition. When this room is loaded as part of a map, the game will use this emoji string to generate its seed and parameters.
    *   This allows for deterministic, thematically seeded rooms within your custom labyrinths.

2.  **In the Main Game (Override):**
    *   On the main game page, near the "Generation Script Editor," there's an "Emoji Seed Override" input field.
    *   If you type an emoji string here and then click "Run Current Script," this emoji string will be used for *that specific run*, overriding any seed or parameters set by the Level Creator for the current room, or any default seed.
    *   This is great for quickly experimenting with different emoji combinations.

### Tips for Emojidex Seeding
*   Check the **Game Log** after generating a room with an emoji string. It will show how the Emojidex processor interpreted your string and the resulting seed and parameters.
*   Experiment! Combine different emojis to see what happens.
*   The `room_params` generated by Emojidex are passed to your `generate_room` script. Your script can then use these parameters (e.g., `if room_params.get("theme") == "fire": ...`).
